# 🎬 PrimeFlix

Aplicação web desenvolvida em **React.js** que consome a API do [The Movie Database (TMDb)](https://www.themoviedb.org/) para listar os filmes em cartaz. O usuário pode visualizar os detalhes de cada filme e salvar seus favoritos no navegador (via `localStorage`).

---

## 🚀 Funcionalidades

- 🔍 Listagem de filmes em cartaz
- 📄 Página de detalhes com sinopse, imagem e nota
- ❤️ Salvar/remover filmes favoritos
- 📂 Persistência dos favoritos usando localStorage
- 🔗 Link para trailer no YouTube
- ✅ Navegação entre páginas com React Router

---

## 🛠 Tecnologias utilizadas

- React.js
- React Router DOM
- Axios
- TMDb API
- CSS

## 📦 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/primeflix.git

# Entre na pasta
cd primeflix

# Instale as dependências
npm install

# Execute o projeto
npm start
```
